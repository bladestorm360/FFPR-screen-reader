## Automatic diagnostic implementation

Shared `timing.h` scopes cover existing guarded readers, mod-issued native calls,
Unity call adapters and mod runtime invocations. Existing title/state/battle hooks
time their native originals and emit rare numeric context markers. This adds no
permanent engine API hook, profiler, input control, speech, setting or native worker
access. In particular the hot runtime gate/all-engine-invoke observer stays removed.

- Slow observed scopes at least5ms record inclusive/exclusive time, parent/span,
  frame/thread and stable native code RVA where available. Nested time is excluded
  from a parent's exclusive total; inclusive totals must not be added together.
- Input intervals at least50ms record gaps that may include native engine/loading/
  waits outside observed reader scopes. A gap alone does not identify its cause.
- Main-owner observed-scope counts/totals/maxima and input intervals summarize
  every5seconds, independent of keys or navigation. Worker slow scopes retain their
  own thread IDs; main summaries do not pretend to cover every worker/native call.
- Normal scopes use clocks/TLS numeric counters without queueing or allocating.
  Only slow events, markers and summaries copy bounded96-byte labels/numeric data
  into the existing2,048-entry logger queue using TryAcquire, with counted drops.
  Label pointers are never retained. Timing formatting and file I/O run on the
  existing logger worker. A blocked/full logger never delays game processing.
- Normal rotating logs retain four-MiB files and five previous files. Diagnostics
  are enabled at logger startup every run and need no toggle or diagnostic key.

The dedicated actual-source check passes nested attribution/unwind, gaps/summaries,
equal work with timing enabled/disabled, temporary labels, held/full queue and worker
serialization. One million identical warm callbacks measured1.088ms without scopes
and34.503ms with scopes: added0.033microseconds per call on this host. This is a warm
offline average, not a universal tail or game-frame guarantee. The real logger lock
held through1,000 producer attempts produced1,000 counted drops without a wait; the
full queue retained exactly2,048 records and counted excess. Serialized records use
owned labels/numbers; producer tests perform no file writes.

Canonical build/all regressions pass:6,736 native name checks/zero missing, zero
undefined wiring,47 exports. Isolated DLL smoke passes forwarding/startup/normal exit,
with the automatic-timing banner in its new log. No additional game was launched to
test this build; actual-game timing evidence above concerns the preceding build.
