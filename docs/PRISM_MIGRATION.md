# FFPR Prism migration, October 12 2026

Implemented, offline-verified, and separately installed in all six FFPR games. The user
requested this migration during the results follow-up, then explicitly requested removal
of Tolk.dll from each game folder after successful deployment. Gameplay/screen-reader
confirmation remains user-side; no game was launched, controlled or probed.

## Source, package and ownership

Active source is the shared native `ffpr-screen-reader` repository. All callers retain
`ffpr::say`/`speech`, current preferences, manual review, Autodetail, event cancellation and
game-specific presentation. Only the worker-owned backend adapter calls Prism. The original
first-native-hook loading gate, fixed ring, settings-save worker, queue/interrupt policy
and shutdown signal remain. No text deduplication or game-loader change was introduced.

Accepted package: [official Prism v0.18.3](https://github.com/ethindp/prism/releases/tag/v0.18.3),
source commit `94329ebeccbaee7f70b3494a290c9dfaac0184ee`, Windows x64 dynamic release.
The DLL and both SDK headers came from the **same** official archive; development headers
were not mixed with a release binary. [Source lock](../prism.lock.json) records all source,
header, runtime and license hashes. Upstream binary build options/toolchain were not
independently reproduced; mandatory PE imports are Windows libraries only, with no delay
imports or CRT redistributable dependency.

- Official archive SHA-256: `13d3c9d1d524b0737cde261c6468845753e36b6c5c2637e7d26bfb8bf4d8783f`.
- Prism DLL SHA-256: `7c7d09c8c7306e8e1a0c46d603ccb2a391c194c77843400c11b746e7dd56a467`.
- Owned destination: each game root's `.ffpr-deps/prism/prism.dll`.
- Receipt: `.ffpr-deps/prism/prism-install.json`, identifying canonical game directory,
  FFPR ownership, x64 architecture, package/version/source and every installed file hash.
- Eleven upstream license/notice files accompany the runtime. Optional Tolk/SRAL/
  UniversalSpeech/SpeechCore wrapper DLLs from the archive are not installed. Pinned NVDA
  source uses native RPC bindings, rather than an external controller DLL. Existing D2R
  and AccessXI Prism packages are unchanged.

The adapter in `src/core/prism_backend.h` derives function types from the pinned C header
and requires all 14 used exports and exact version. LoadLibraryEx uses an absolute path
relative to the owning hid.dll, with DLL/system search flags. A missing/incompatible
package fails safely with a concise installer diagnostic and leaves the worker available
for settings persistence. Acquired backends may return ALREADY_INITIALIZED; this is valid.
Backend references are freed before context shutdown and library unload, on the owning
worker. No backend API is called by reader hooks or DLL detach.

UTF-16 queue text becomes validated UTF-8 on that worker. Normal output uses combined
speech/braille when advertised; otherwise it preserves separate available speech/braille
channels. Braille-only stays braille-only. Feature checks gate unsupported braille/stop;
voice/rate/pitch controls are not newly forced into a user's screen reader. Submission
success is not evidence that the user heard an announcement.

## Separate installation and normal deployment

`install_prism.bat [ff1..ff6]` is an explicit dependency operation. `--game-root "path to
steamapps/common"` supports other Steam libraries. It checks affected game processes are
closed, verifies the entire source/staged package, serializes installers with a file lock,
then commits verified files and a receipt. Matching unreceipted files are adopted with a
receipt only. Foreign receipts/files are rejected; owned package updates preserve paired
backups and restore files/receipt if commit fails. Temporary deletion is restricted to
the exact validated staging directory created by that operation.

An unchanged verified install performs zero writes, including preserving receipt/runtime
hashes and last-write timestamps. Only the separate installer may repair or update Prism.

`deploy.bat [ffN]` checks the **same** target game directory read-only, then copies hid.dll
and SDL3.dll. It never invokes the installer or copies/downloads/repairs/upgrades Prism,
licenses, receipts or backups. Build/CMake only consumes pinned headers and runs offline
checks. `tools/make_release.py` now produces a mod-only archive; a requested prerequisite
distribution must be packaged separately. No release archive was generated by this task.
